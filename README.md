# Fork-Knife

## Project Overview
**Fork-Knife** is a dynamic web application designed to bridge the gap between home cooks and global cuisines. By integrating with a professional-grade recipe database, the app allows users to explore thousands of dishes, filter by dietary needs, and search for specific ingredients. 


## Technologies Used
- HTML
- CSS
- JavaScript 
- Fetch API

## API Used
- TheMealDB API

## Planned Features

- **Real-time Search:** A dedicated search bar that filters through recipe titles.
- **Dietary Filtering:** Category-based filtering (e.g., Vegetarian, Dessert, Beef) implemented via Array HOFs to update the state dynamically.
- **Alphabetical & Complexity Sorting:** An interactive toggle to sort recipes by name or by the number of ingredients.
- **Instruction Modals:** A detailed view for each recipe, showing measurements, step-by-step instructions, and YouTube tutorials.
