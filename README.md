# 🍴 Fork-Knife — Global Cuisine Explorer

## 📌 Project Overview
**Fork-Knife** is a dynamic web application that helps users discover recipes from around the world. By integrating with a professional recipe database, the application allows users to explore hundreds of dishes, filter them by category, and search for specific recipes instantly.

The goal of the project is to provide a simple and interactive way for users to explore global cuisines and learn how to prepare them.

---

## 🚀 Features

- 🔎 **Real-time Search**  
  Search for recipes by name and instantly filter the results.

- 🥗 **Category Filtering**  
  Filter recipes by category such as **Beef, Dessert, Chicken, Seafood, Vegetarian**, etc.

- 📖 **Recipe Detail Modal**  
  View complete recipe details including:
  - Ingredients with measurements
  - Step-by-step cooking instructions
  - YouTube cooking tutorial

- ⚡ **Dynamic Data Fetching**  
  Recipes are fetched dynamically using the **Fetch API**.

- 📱 **Responsive Design**  
  Layout adapts to different screen sizes for better usability.

---

## 🛠 Technologies Used

- **HTML5** — Page structure  
- **CSS3** — Styling and responsive design  
- **JavaScript (ES6)** — Application logic and interactivity  
- **Fetch API** — Fetching recipe data from the API  

---

## 🌐 API Used

This project uses the **TheMealDB API**.

Example endpoint:

```
https://www.themealdb.com/api/json/v1/1/search.php?f=a
```

Official API documentation:  
👉 https://www.themealdb.com/
